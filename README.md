# Dipak — Professional Full Stack Developer Portfolio

A modern, high-performance developer portfolio built with **React**, **Vite**, and **Tailwind CSS**, designed specifically for technical interviews and recruiter evaluation.

---

## 🚀 Live Local Preview

Your portfolio is running locally at:
👉 **[http://localhost:5173/](http://localhost:5173/)**

---

## 🛠️ How to Customize Your Portfolio

All your data is centrally located in **one file**:
📁 [`src/data/portfolioData.js`](src/data/portfolioData.js)

You can easily update:
1. **Personal Information**: Name, title, email, phone number, location, GitHub, and LinkedIn links.
2. **Projects**: Add your own project titles, descriptions, metrics (e.g. latency reduction, users served), GitHub repositories, and live demo links.
3. **Skills**: Add or remove frontend, backend, database, and DevOps technologies with proficiency levels.
4. **Experience & Education**: Update your companies, roles, graduation details, and certificates.
5. **Interview Summary**: Customize the 60-second summary and starter Q&A in the "For Interviewers" modal.

## ⚡ Useful Commands

In PowerShell or terminal:

```bash
# Start local development server
npm run dev

# Build optimized production bundle
npm run build

# Preview production build locally
npm run preview
```

## 🌐 Free 1-Click Deployment (Vercel / Netlify)

1. Push this repository to your GitHub account:
   ```bash
   git init
   git add .
   git commit -m "Initial portfolio commit"
   git branch -M main
   git remote add origin https://github.com/<your-username>/<your-repo-name>.git
   git push -u origin main
   ```
2. Go to [Vercel](https://vercel.com) or [Netlify](https://netlify.com).
3. Import your GitHub repository.
4. Click **Deploy**! (Vite build settings are detected automatically).
